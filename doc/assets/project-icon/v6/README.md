# Cli 柔和人文版 · v6

用户认可 v5 的基本设计样式，本版沿用 Cli 与对话框的组合，通过更自然的 C 形曲线、柔和尾部、光学比例及浅蓝圆点增加亲和感。保持扁平风格、粗笔画、蓝色和透明背景。

已在浏览器实看明暗背景：24px 可辨识 Cli，32px 与 48px 的间距、圆点及尾部更清楚，建议页面标题采用 32px。预览是原图按实际尺寸显示，未通过绘图脚本重画；背景与文字不属于透明 PNG。

保留所有历史版本，本版尚未接入插件。仅更新设计素材与文档，没有修改业务代码、安装版本或运行业务测试。

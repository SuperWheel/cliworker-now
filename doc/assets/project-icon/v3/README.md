# CLI Worker Now · 会话可见 Logo

本版是项目 Logo 设计稿，尚未替换插件中的图标。保留 v1、v2 的历史素材和选择状态。

![明暗主题与小尺寸预览](preview.png)

## 设计含义

- **打开的会话窗口**：以开口的圆角对话轮廓表达主对话与侧栏中的可见工作过程。
- **三条并列会话**：代表多个子 Agent 独立运行、分别查看的对话记录。
- **实时状态圆点**：表达正在发生的工作，对应项目名称中的 Now。

采用蓝色双调、圆角和扁平形状。没有沿用前一版的终端提示符；同一张透明 PNG 可用于亮色与暗色背景。

## 文件

- [透明原图](cliworker-now.png)：1254 × 1254 RGBA PNG，不含底板和文字。
- [应用预览](preview.html)：用实际 PNG 展示明暗主题、名称组合及 24px／32px／48px 尺寸。文字和背景只属于预览页。

生成图复制到项目后没有修改像素。已确认四角透明、没有不透明背景，并在浏览器查看亮暗背景及三个小尺寸；本轮未修改业务代码或已安装版本，未运行业务测试。

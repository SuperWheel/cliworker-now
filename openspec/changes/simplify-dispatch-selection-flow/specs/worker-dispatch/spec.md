# Spec Delta

## MODIFIED Requirements

### Requirement: 选型和宿主权限保持
派遣 SHALL 以项目和 CLI 隔离模型、思考强度和角色的完整设定，并按主对话确认是否沿用。子 Agent、宿主规划或整体只读状态 MUST 拒绝外部执行。未完成选择和取消选择后 MUST 不启动进程，且不得保存部分设定。复用设定 MUST 仍核验当前账号、模型与强度。

#### Scenario: 首次使用与取消
- **WHEN** 用户首次调用一个未保存完整设定的 CLI，随后取消选型
- **THEN** 不产生 Worker 进程，不自动选择模型，不保存半套设定

#### Scenario: 宿主拒绝执行
- **WHEN** 主会话处于规划模式或整体只读状态，或调用来自子 Agent
- **THEN** 返回原有权限拒绝，名称别名不得绕过边界

#### Scenario: 旧版偏好
- **WHEN** 项目只有旧版模型和强度偏好，尚未确认角色
- **THEN** 首次派遣询问完整设定，不从历史任务猜测角色

## ADDED Requirements

### Requirement: 项目设定与主对话确认
首次派遣 SHALL 询问模型、模型支持的思考强度及角色并保存完整设定。相同项目和 CLI 的新主对话 SHALL 先询问是否沿用以前设定；同一主对话后续派遣 SHALL 使用自身已经确认的设定，Host 重启后仍有效。明确选择不使用角色 SHALL 视为完整设定。

#### Scenario: 新对话沿用
- **WHEN** 项目和 CLI 已有有效完整设定，新主对话首次派遣并选择沿用
- **THEN** 只出现一次沿用询问，任务使用既有模型、强度与角色

#### Scenario: 新对话重新选择
- **WHEN** 新主对话选择不沿用
- **THEN** 询问模型、强度及角色，完成后更新该对话和项目设定

#### Scenario: 同一对话继续派遣
- **WHEN** 已确认设定的主对话再次派遣相同 CLI
- **THEN** 不再次提问，其他对话修改项目默认不改变该对话已确认设定

#### Scenario: 项目或 CLI 不同
- **WHEN** 请求切换项目或 CLI
- **THEN** 对应设定独立读取与确认，不跨项目、CLI 或主对话代答

#### Scenario: 账号或模型变化
- **WHEN** 已确认设定的账号来源改变或模型、强度不再有效
- **THEN** 不静默替换账号或模型；可选目录有效时进入完整选型，无可用目录时返回简短错误且不启动

#### Scenario: 设置页更新默认
- **WHEN** 用户在设置页更改项目的模型和强度
- **THEN** 后续新主对话沿用更新后的默认及已确认角色，已有对话与 Worker 的快照保持不变

### Requirement: 仅两类简洁派遣询问
插件派遣 SHALL 仅生成“模型、思考强度、角色选择”和“是否沿用以前设定”两类询问。选型 MUST 只提供实际模型支持的强度；问题卡 SHALL 省略灰色选项描述、项目路径和说明段落。工具指引 SHALL 要求直接进入插件流程，不要求主 Agent 自行提前提问或增加确认。

#### Scenario: 选择问题卡
- **WHEN** 用户进行完整选型
- **THEN** 问题卡仅含必要标题、问题和选项，不显示免费额度、项目路径和额外说明

#### Scenario: 强度随模型
- **WHEN** 用户选择不同模型
- **THEN** 后续强度选项与该模型实际能力一致；唯一强度可直接采用，不生成额外确认

#### Scenario: 沿用问题卡
- **WHEN** 需要确认是否沿用
- **THEN** 展示既有设定和沿用或重新选择两个选项，不新增第三类问题

### Requirement: 询问并发和取消隔离
相同主对话、项目和 CLI 的并发派遣 SHALL 顺序共享已确认结果，不重复询问；不同主对话 SHALL 独立确认。等待者取消 MUST 及时结束且不取消其他调用的询问；询问发起者取消后其他等待者 SHALL 能重新取得选择机会。插件关闭 MUST 清理等待和询问状态。

#### Scenario: 同对话并发
- **WHEN** 同一对话在首次选型未完成时再次触发相同 CLI
- **THEN** 同时仅一套问题，完成后两个请求均使用同一完整设定

#### Scenario: 不同对话并发
- **WHEN** 不同主对话同时触发同一项目和 CLI
- **THEN** 各自完成自己的选型或沿用确认，不共享未确认答案

#### Scenario: 等待或选择取消
- **WHEN** 某等待者或当前问题发起者取消
- **THEN** 对应调用结束，未完成设定不写入，其他调用可以继续，等待状态最终清理

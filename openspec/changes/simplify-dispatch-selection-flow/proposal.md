# Proposal

## Why

当前 `src/host/index.ts` 对已保存的模型静默复用，却每次新任务都询问角色，并将项目路径和选项说明放进原生问题卡。用户要求按项目、CLI 和主对话管理完整设定，询问仅限选型与是否沿用两类。

## What Changes

- 首次选择模型、实际支持的思考强度与角色，全部确认后保存完整设定。
- 同项目同 CLI 的新主对话只询问是否沿用；否才重新选型。同一主对话后续直接使用已确认设定。
- 删除问题卡的项目路径、说明段落和灰色选项描述；同步工具指引，不生成额外确认。
- 保留账号、模型、强度执行校验和既有 Worker 角色；取消不保存半套设定，不启动任务。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `worker-dispatch`: 完整项目设定、逐主对话确认、两类简洁询问及并发取消行为。

## Impact

Host 的派遣编排、私有存储、角色问题构造和提示指引；Client 等待状态；相关测试、README 与设计验证记录。公开模型偏好协议兼容，不改 Harness 核心、CLI 认证或原生保护，不触发真实模型生成。先隔离构建与界面验收，再于 Desktop 空闲时更新并本地提交。

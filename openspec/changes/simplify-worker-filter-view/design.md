# Design

## Context

panel在query或非all筛选时生成统一cwn-filter-info分支，显示数量/空结果及清除筛选，CSS单独控制该行间距。列表过滤本身在visibleWorkers处理，不依赖该行。

## Goals / Non-Goals

只移除信息栏，不修改过滤逻辑、卡片、初始空页、回收列表或持久化。

## Decisions

删除完整JSX分支与失去使用点的CSS，从生成源头移除；不用CSS隐藏。搜索清空与全部按钮仍是原生恢复入口，测试通过这些入口恢复列表并检查草稿保持。

## Risks / Trade-offs

- 移除清除筛选快捷入口 → 保留搜索编辑及全部按钮，覆盖正向、空结果与恢复。
- 空状态可能误显示启动页 → 所有三类状态及搜索空结果核对列表空白，初始页/已删除页仍区分。

## Migration Plan

无数据迁移。preview隔离界面核查后，无活动任务时更新Desktop v0.7.6；正式界面和历史数据核对，本地阶段提交、同步规格并归档。

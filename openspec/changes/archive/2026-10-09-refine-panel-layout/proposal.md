# Proposal

## Why

v0.7.2 的管理弹窗输入未铺满、留白过多，总览整页滚动使搜索和筛选离开视野；名称复制图标扩大了元信息间距。历史续聊提示和启动页也需要更紧凑、清楚的呈现，按用户四张截图进行本轮调整。

## What Changes

- 名称及聊天标题弹窗共用紧凑布局，输入与保存按钮右缘对齐。
- 总览固定搜索与四个筛选按钮，仅下方任务区域滚动；已删除入口改为异常右侧的淡红垃圾桶按钮。
- 名称复制不显示图标；成功后文字显示已复制，离开或失焦约一秒后恢复。
- 历史账号缺失提示与新建对话合并为标题下的圆角横条，原权限及重新验证行为不变。
- 初始空页不放图标、CLI列举或大块示例，只保留温和标题和一句简短行动提示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `worker-management`：名称复制、旧历史新建入口的呈现，以及管理弹窗与总览布局。

## Impact

只调整 React Client 与对应行为测试；Host、公开协议、账号来源、原生CLI会话和权限不变。沿用 Harness 控件与主题，不修改核心或用户 skill。先 preview 原生界面模拟验收，空闲时更新 Desktop，核对账号历史后本地提交，不推送；本轮不发起真实模型生成。

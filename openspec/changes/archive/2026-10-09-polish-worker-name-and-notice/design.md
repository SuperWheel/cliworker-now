# Design

## Context

见 proposal.md。rc.2 私有侧栏展开按钮为38px，没有公开高度token；当前局部状态条为32px。NameCopy内原生Tooltip不生成布局外壳，4px内边距和全角分隔符空白造成字距不对称。

## Goals / Non-Goals

局部Client布局适配，无Host、Gateway、持久化或账号修改，不改变退役CLI提示和续聊准入条件。

## Decisions

- 状态条min-height38px、border-box和5px上下内边距，内部原生按钮28px，保持单行与主题。只修改本插件样式，不改宿主私有源码。
- 删除生成输入区说明的JSX条件分支；保留canResume与表单/按键校验，不从DOM遮挡提示。
- 名称左右内边距8px配合-4px外边距，扩大边界同时保持文字起点。flex填充保持长名可用宽度，包裹层仍限制38%。用aria-hidden的1px线替代全角字符；模型前加4px，两侧以文字边缘计算为普通11px、窄栏9px，按钮到线分别3px/1px。直接增加padding会移动名称；放大伪元素会让点击边界与背景不一致，故不用。

## Risks / Trade-offs

- 长名截断/负边距可能越界 → 隔离原生UI测短名、长名、窄栏文字与按钮矩形及复制交互。
- 删除说明误开放发送 → 回归无会话的输入、按钮、键盘及强制提交，保留历史/草稿/错误。
- 私有原生高度将来变化 → 记录适配rc.2来源，本次实测对齐，不发明设置桥。

## Migration Plan

preview隔离渲染验收后，确认无活动任务及账号终端，退出Desktop正式构建更新；保留账号、偏好和历史。本地阶段提交与规格同步归档，不推送。回退Client包即可，无数据迁移。

# Spec Delta

## ADDED Requirements

### Requirement: Hermes Nous 自身账号目录
Hermes 的 Nous 目录 SHALL 使用当前自身原生登录及官方认证元数据，结合账号访问范围与原生聊天能力筛选。公共 fallback、仅登录成功或默认模型配置 MUST 不独立成为可选依据；已登录却缺少服务商实现不能伪装成账号无权益。

#### Scenario: Nous 授权已写回
- **WHEN** Hermes 当前独立账号中的 Nous 授权有效，官方元数据确认账号模型及权限
- **THEN** 展示其与原生聊天能力的模型/强度交集；无需重新登录或借其他 CLI 账号

#### Scenario: 无付费权限
- **WHEN** 当前 Nous 账号没有付费访问权
- **THEN** 只开放官方明确允许该账号访问的免费模型，未知价格或通用目录不作为免费证据

#### Scenario: 目录异常或取消
- **WHEN** 请求被拒绝、超时、重定向、返回无效数据，或用户取消
- **THEN** 不回退公共目录，不生成试探，不自动续期；结束请求并给出简短原因，原登录信息按自身证据保留

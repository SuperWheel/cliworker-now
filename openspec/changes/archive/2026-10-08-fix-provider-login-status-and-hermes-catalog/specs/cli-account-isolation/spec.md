# Spec Delta

## ADDED Requirements

### Requirement: Hermes Nous 账号绑定
Hermes Nous 的登录摘要、模型发现与执行 SHALL 使用相同的自身来源和原生认证路由。账号版本 MUST 绑定原生运行时实际使用的认证，保存、出队、启动与续聊继续执行现有重检；静态配置或过期快照不得恢复退出的账号。

#### Scenario: 当前原生运行认证
- **WHEN** 原生 Nous 账号包含网页登录令牌和运行时认证字段
- **THEN** 模型查询与绑定核对原生实际用于推理的字段、当前身份和路由，不仅检查任意非空令牌

#### Scenario: 账号改变或注销
- **WHEN** 查询过程中或已选模型后，当前自身账号退出、换号或不可用
- **THEN** 旧模型结果和选型失效，不回退全局账号、不从旧 Worker 恢复认证

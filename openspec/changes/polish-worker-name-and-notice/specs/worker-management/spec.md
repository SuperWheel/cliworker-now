# Spec Delta

## MODIFIED Requirements

### Requirement: 缺失账号历史的新对话入口
缺少账号绑定的历史任务 SHALL 在标题下通过紧凑圆角提示条显示简短阻塞原因及新建入口，不允许旧会话续聊。用户明确新建时 SHALL 保留旧记录和草稿、沿用原 CLI/模型/强度/角色并重新核对当前自身账号；新对话 MUST 使用新 Worker/原生会话，不伪造旧账号身份。

#### Scenario: 查看与新建
- **WHEN** 旧任务有会话 ID 但缺少账号证据
- **THEN** 历史仍可查看，续聊被阻止，用户可通过新建对话操作发送到新的同 CLI Worker

#### Scenario: 新建失败或账号变化
- **WHEN** 新建时账号未登录、模型失效、账号改变、权限不允许或请求取消
- **THEN** 不启动或继续旧会话、不静默换模型或账号，草稿与旧记录保持

#### Scenario: 提示位置
- **WHEN** 打开缺账号证据的旧对话或进入新建状态
- **THEN** 提示及对应操作保持在标题下方，输入区不再重复显示；新建和取消行为保持

#### Scenario: 状态条高度
- **WHEN** 展开侧栏查看历史账号阻塞提示或新建状态
- **THEN** 标题下单行提示条与宿主展开侧栏的新会话按钮高度一致，文本与操作垂直居中

### Requirement: 名称复制
智能体名称 SHALL 独立显示悬停及聚焦反馈，点击或键盘激活复制确切名称且不打开卡片；不显示复制图标或保留其占位，扩大按钮左右留白时名称文字起点 MUST 保持；名称末端与模型起点到细分隔线的距离 SHALL 相等，按钮边缘到线仍有小间隙。成功后按钮文字 MUST 显示已复制，鼠标离开或键盘失焦约一秒后恢复名称。复制失败 MUST 如实提示，结果状态与定时器随组件销毁清理。

#### Scenario: 独立复制
- **WHEN** 用户悬停名称并点击或键盘激活
- **THEN** 显示复制反馈、复制短名称，卡片仍停留原页面；失败时保留可选择文本

#### Scenario: 文字反馈时机
- **WHEN** 复制成功后仍悬停，随后移开鼠标或完成键盘操作后失焦
- **THEN** 悬停期间保持已复制，离开约一秒后恢复；多次进入离开、名称变化和销毁不遗留计时器或过期反馈

#### Scenario: 文字距离及窄栏
- **WHEN** 查看普通或窄栏中的短名、长名卡片
- **THEN** 名称按钮左右包住可见文字，分隔线两侧文字距离相等；长名可省略且控件不越界，复制仍使用确切完整名称

## ADDED Requirements

### Requirement: 简洁的无会话输入区
结束后没有原生会话ID的任务 SHALL 保留历史、错误与草稿，但不在输入框上方显示无法续聊的说明小字。输入及提交 MUST 继续被禁用，不恢复账号或伪造可续聊状态。

#### Scenario: 无原生会话
- **WHEN** 任务结束且没有会话ID
- **THEN** 无输入区说明小字，原有运行错误仍可见；键盘、按钮或强制表单提交均不能启动续聊或新建，历史与草稿保持

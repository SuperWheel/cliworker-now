# Design

## Context

见proposal中的六项问题。总览控件和滚动列表已经分离，但列表零顶部内边距会裁切首组elevation描边；四筛选与showArchived两个独立状态缺少返回转换。WorkerCard的箭头归属首行，而NameCopy没有水平内边距。共享展示函数去掉一层提供商后仍留下Hermes组织路径。

## Goals / Non-Goals

**Goals:** 从状态转换和布局结构上修正问题，保留原生Menu/Tooltip、主题、固定控件和生命周期，全部展示位置使用同一名称和强度格式。

**Non-Goals:** 不改变真实账号、历史、权限、模型ID、模型目录合并键或执行参数，不用远端生成验收。

## Decisions

- 滚动列表内增加顶部留白，保证描边在滚动边界内；不取消overflow或移动固定控件。回收站仍是独立视图，四筛选动作同时退出该视图，aria-pressed反映当前视图；再次点击垃圾桶保留旧筛选。
- 卡片箭头跨标题和元信息两行居中，去掉可见省略号；原生Menu通过右键与可聚焦开卡片按钮的键盘快捷键打开，保留原生焦点恢复。名称按钮左右对称内边距，复制计时语义不变。
- 仅显示阶段取原生名称的末段，nativeModelName继续保留原生组织路径用于分组。显示碰撞仍用可逆选项保留不同ID。default共享label改为默认，协议字符串保持default。
- 用回收站到四筛选、右键/键盘、异步复制和完整ID选择回归覆盖行为；实际首卡描边、箭头中心、名称按钮包围、颜色和无省略号由隔离原生UI核对。

## Risks / Trade-offs

- [短名称碰撞] → 不改变分组身份，保留选择映射及各自能力，测试不同组织同名模型。
- [移除Menu按钮损失焦点] → 使用原生anchor及开卡片按钮恢复焦点，测试菜单关闭与键盘激活。
- [滚动恢复裁切首卡] → 验收首次打开、滚回顶部及子对话返回；长列表阅读位置保持。

## Migration Plan

无需数据迁移。以v0.7.4隔离preview验收，确认无活动任务及账号终端后退出Desktop，正式build/pack并重启核对版本、界面和原账号/历史哈希；分阶段本地提交，不推送。
